Presentación HTML5 con tres vistas: organigrama académico, administrativo e integrado. Contiene los emblemas del IER y de la UNAM, recorridos guiados y capas interactivas.

**Estado de preparación:** pendiente de incorporar el archivo `index.html` y habilitar GitHub Pages. No se declara el sitio publicado.

### Publicación

1. Cargar en la raíz de `main` el archivo HTML de la versión 0.10 con el nombre `index.html`.
2. En **Settings → Pages → Build and deployment**, elegir **Deploy from a branch**, rama **main**, carpeta **/(root)** y guardar.
3. Comprobar el despliegue en **Actions** y abrir la dirección que muestre **Settings → Pages**.

El archivo `.nojekyll` ya está preparado. No se requieren dependencias ni una compilación propia.
